# 可点击演示版 · 使用说明

**打开方式**：双击 `index.html`，用 Chrome / Edge / Safari 打开即可。无需安装、无需联网、无需服务端。

整个演示版是**一个 HTML 文件**（约 188 KB，CSS 与 JS 全部内联，零外部依赖），可以直接微信/邮件发给协会那边点。

---

## 一、这版能点出什么

### 1. 四级菜单树（不是一层平铺）

左侧是真正的多级菜单：**11 个一级模块 → 58 个末级页面，最深 4 级**。

```
系统设置 › 角色与权限 › 权限矩阵 › 按角色查看
  一级        二级         三级        四级
```

- 带 `▶` 的是可展开的分组，点一下展开/收起；当前页的祖先节点会自动展开并高亮。
- 末级菜单前有小圆点，点它就是切页。
- 顶部面包屑显示完整层级，**每一级都可点**，点「项目管理」会回到该模块的第一个页面。
- 菜单按角色裁剪：总管理员 58 页、协会管理员 50 页、财务与核销 44 页、会务执行人员 40 页、普通用户与嘉宾 19 页。

### 2. 总管理员是超级角色（不用切身份）

右上角「角色」切到 **总管理员（全平台）**，顶栏会多一个绿色标签「全部权限 · 全平台」，表示当前身份不受任何限制：

- **11 个一级模块全部「全权」**，不是只读 —— 立项审批、核销 6 步判定、例外单处理、生成结算单、生成卷宗、合同/招商/嘉宾等资料录入，都能直接做。
- **数据范围「全平台」**：28 个项目全可见（协会管理员 4 个、执行 10 个、财务 12 个、普通用户 1 个）。
- **待办中心看全部角色的待办**（6 条，含「财务专属的结算待触发」和「嘉宾专属的待签到」），并且多一列「归属角色」，一眼看出这条活本来该谁干。
- **权限矩阵**里总管理员那一行 11 个「全权」，页面顶部写明「其余四个角色的权限都是它的子集」；下面还多一张「数据范围与规模」表，把 5 个角色的可见项目数、可写模块数摆在一起对比。
- 「成员与授权」表单里可以授予「总管理员（全平台）」身份。

### 3. 表单是真的能填能校验的

全站 **16 张表单**，分两种形态：

| 形态 | 例子 | 行为 |
|---|---|---|
| 整页表单 | 立项申请、会务需求确认 | 直接在页面里填，必填项留空会标红并提示 |
| 弹窗表单 | 新增合同 / 招商 / 嘉宾 / 议程 / 任务 / 付款 / 报销 / 例外单 / 变更 / 成员 / 协会 / 通知 | 点右上「+ 新增」弹出，提交后列表当场多一行 |

必填校验覆盖**全部 8 类控件**：文本框、下拉、日期、数字、多行文本、复选组、文件选择。
必填下拉默认是「请选择…」，不选就是空，**不会被默认值蒙混过关**；留空提交时每个必填项逐项标红，并提示「请先填写所有必填项」。
弹窗表单底部有 **重置**（清空重填）/ 取消 / 提交；文件框点开是真的系统选文件对话框，选中后回显文件名（演示版不落盘）。
**提交会真的落到内存数据里**：立项申请提交后项目数 +1、自动生成一条待审批、审计日志多一行、并跳转到「待我审批」。

### 4. 列表都有分页，导出是真文件

会议项目 28 条（12/页）、审计日志 41 条（12/页）、合同 16 份、嘉宾 24 人、付款 12 笔、登录日志 16 条……超过一屏的列表底部都有「共 N 条 · 每页 N 条 + 页码」，点页码真翻页。

列表页右上「导出」会**当场下载一个带 BOM 的 CSV**（Excel 双击打开不乱码），文件名形如 `全部项目-10-18_1218.csv`，
同时自动写一条「导出记录」+ 一条审计日志 —— 导了什么都留痕。已归档项目还能「导出卷宗」，
生成含**核销 6 步结论 / 结算金额 / 例外单 / 审计留痕**四段的文本卷宗。

### 6. 全流程总览（一屏讲清整条链路）

「工作台 › 数据看板 › 全流程总览」是专门给汇报用的：7 段流程条（每段显示当前停在几个项目，点一下直接跳到该阶段工作页）
+ 在库/卡核销/已归档三个 KPI + **阶段职责与闸门**表（谁负责、做什么、卡什么）+ 核销 6 步 SOP + 三条硬约束 + 9 状态 8 流转的状态机。
讲的时候不用背，照着屏幕念就行。

### 7. 项目上下文

筹备 / 会务需求 / 会务执行 / 材料中心 / 会后核销 / 财务结算 六个区域右上角都有**项目下拉**，切换后标题、金额、汇总条一起变。
合同与招商金额按当前项目预算等比缩放，不会出现「合同总额 > 会议预算」这种矛盾。

## 二、建议的演示动线

### 动线 A：看系统骨架（2 分钟）

1. 展开左侧「系统设置 › 角色与权限 › 权限矩阵」→「按角色查看」：总管理员一行 **11 个「全权」**、可见项目 **28 / 28**；下面「数据范围与规模」表把 5 个角色的可见项目数、可写模块数摆在一起。
2. 再点「按模块查看」——11 个模块 × 5 个角色，总管理员列表头带 ★，整列都是「全权」。
3. 点顶部面包屑回到「系统设置」，进「组织与协会」，看 16 个协会的层级。
4. 右上角切到 **普通用户与嘉宾**，侧栏从 58 页缩到 19 页、可见项目从 28 个缩到 1 个 —— 这就是数据范围；切回总管理员，一切恢复。

### 动线 B：走一遍硬约束（3 分钟）

先打开「工作台 › 数据看板 › 全流程总览」，把 7 段链路和三条硬约束过一遍，再开始点。

1. 右上角选 **财务与核销** → 「财务结算」→ 切到 `MP-2026-004 外科沙龙 2026`，**整页锁定**，页面写明「6 步已通过 3/6，2 张例外单未闭环」。
2. 切到 **会务执行人员** → 「会后核销」→ 把某一步判 **不通过**，自动生成例外单，财务侧仍然锁定。
3. 回例外单卡片点 **标记已解决** → 该步自动转「通过」。
4. 补齐剩余步骤 → **提交核销结论** → 状态 待核销 → **已核销**。
5. 切回 **财务与核销** → 蒙版消失 → **生成结算单** → **已结算**。
6. 切到 **总管理员** → 「档案中心」→ **生成卷宗** → **已归档**（项目冻结）。
7. 打开「审计日志」→ 41 条里能看到刚才每一步。

### 动线 C：试表单（1 分钟）

1. 「项目管理 › 立项管理 › 立项申请」→ 直接点「提交」，**8 个必填项**逐项标红（含两个下拉）。
2. 填完再提交 → 项目数 28→29，自动跳「待我审批」，多出一条待办。
3. 任意弹窗表单点「重置」→ 已填内容清空、红框消失，可以重填。
4. 「财务结算 › 付款申请」→ 「+ 付款申请」→ 选 `MP-2026-004`（待核销）→ 提交会被**硬约束拦下**，弹窗保留、输入不丢，并写明拦截原因；
   把关联项目换成 `MP-2026-008`（已核销）再提交 → 通过，付款列表多一行。
5. 「项目管理 › 全部项目」右上「导出」→ 浏览器直接下一个 CSV，再去「审计日志 › 导出记录」看它被记了一笔。

## 三、几道「点不动」的硬约束（这是重点，不是 bug）

- 6 步没全通过、或例外单没闭环 → **提交核销结论**按钮是灰的，财务整页锁定。
- 付款申请挂在未核销项目上 → **提交被拒**，只留一条「付款申请被拦截」审计，不产生任何付款记录。
- 已结算 / 已归档的项目 → 核销 6 步变成只读，显示「结论已归档，不可修改」。
- 已结算的项目 → 财务页不再出现「生成结算单」，改为「结算已完成 · ¥xxx」，**不会重复付款**。
- 已核销但未结算的项目 → 档案中心的「生成卷宗」不可点，提示「需先结算」。
- 角色数据范围是真的收窄的：财务角色看不到「审计日志」；执行人员在核销页的项目下拉里选不到已结算 / 已归档的项目。

## 四、关于数据

- 全部是**演示假数据**，写死在 HTML 里的常量中，刷新页面即回到初始状态（不落库、不写 localStorage）。
- 28 个项目的会议名、协会、预算、日期、负责人、核销进度**互相自洽**：已核销 / 已结算 / 已归档的项目核销进度都是 6/6，有例外单的步骤一定处于不通过状态。
- 合同总额按项目预算封顶（基准 24 万的会议，16 份合同合计 ¥238,000），切到小预算会议会等比缩放，不会出现「合同 > 预算」。
- 财务金额按预算推导（公付 35% / 报销 5% / 厂家 42%），切项目时四张卡和结算单一起变，合计与明细对得上。
- 顶部始终挂着橙色标签 **「演示数据 · 非真实业务」**，避免被误当成正式系统。

## 五、兼容性

- 浏览器：Chrome / Edge / Safari 近两年版本均可（用了 CSS Grid、Flex、`place-items`）。
- 屏幕：1280 及以上最佳；1024 宽会自动收窄侧栏，列数特别多的表（如例外单）在该宽度下可横向滚动，不会裁字。
- 不需要任何本地服务，`file://` 直接打开即可。
