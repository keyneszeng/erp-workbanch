# 会议邀请函微信小程序入口（最小工程）

这是“企业邀请（招商）/嘉宾邀请”功能的移动受邀页面，不是完整的协会 ERP 小程序。

## 接入
1. 在微信公众平台注册小程序、获取真实 AppID，把 project.config.json 的 touristappid 替换为真实值。
2. 将 https://erp.aibuild.work 配置成小程序 request / downloadFile 合法域名并完成相应备案、校验。
3. 将小程序上传微信开发者工具并发布审核通过。未发布前，ERP 只生成 share path，不能断言用户已收到消息。
4. ERP 中由授权人员对已立项/筹备中会议创建邀请函，生成 path: pages/invite/index?token=...。
5. 在小程序内使用 onShareAppMessage 分享卡片；受邀者进入页面后可查看 PDF、确认/拒绝，回复回写项目邀请记录。

## 注意
- 点击分享不等于平台已送达；不要标记为“已发送”。
- 一份邀请函的 Token 仅针对受邀对象，不应公开批量传播。
- 本工程只处理邀请函；报名签到、材料收集等页面仍需与完整小程序项目整合。
